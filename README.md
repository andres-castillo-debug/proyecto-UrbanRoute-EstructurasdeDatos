# Proyecto UrbanRoute
Integrantes:

Descrición:

UrbanRoute es una herramienta de software desarrollada en Java que modela una red de transporte urbano (basada en el Metro de Caracas) 
como un Grafo Ponderado No Dirigido. El sistema utiliza una Tabla Hash implementada desde cero para la indexación eficiente de estaciones, 
permitiendo calcular rutas óptimas, detectar zonas aisladas tras simulaciones de fallas y visualizar la red de forma interactiva.
